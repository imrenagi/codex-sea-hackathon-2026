Jalan Kita — original asset refinement, 7 November 2026

Vehicle geometry is derived from this project's original indonesia_traffic_pack
Blender generator. The source pack is unchanged. Detailed derivatives retain its
fictional designs, wheel sockets, lamp groups, and gameplay envelopes. No CARLA
meshes, textures, names or code were copied. Three cars have near/far meshes.
The detailed BeAT/motor bebek source bodies and their label derivatives are unchanged.

Surfaces/asphalt, Surfaces/marking and Surfaces/weathered_plaster are original
mathematical noise/material maps, generated by tools/fidelity/surfaces.py using
Blender and NumPy. No photograph or reference-image pixels are included.

Trees use original branch/crown geometry and the previously generated original
leaf texture; see NOTICE.txt for its generation prompt. Existing bark, clay tiles,
plaster and paving maps remain the project's documented CC0 Poly Haven surfaces.
StreetReflection.asset is a small cubemap rendered from the project's own Kenanga
scene. It is a shared approximate environment reflection, not a live per-car probe.

Runtime visual code is additive. Road dimensions, scenario rules, vehicle controls,
collision footprints, lamp logic, passenger boarding and existing vehicle choices
remain unchanged. Cars and trees have distance LODs. This pass adds one downsampled
screen-space ambient occlusion feature and enables the renderer's postprocess data.
FidelityChecks.Prepare prepares import settings/material variants/reflection;
FidelityChecks.Run also runs existing traffic, player, mission and exploration
checks and captures real Unity camera renders. It does not build or control the
shared game application.
